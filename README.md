# Telegraph Messenger

Python-месенджер із Tkinter frontend та WebSocket backend.

## Структура

- `frontend/interface/` — графічний інтерфейс.
- `frontend/Connection/` — клієнт WebSocket, авторизація та шифрування.
- `backend/server.py` — сервер, користувачі та збереження зашифрованих повідомлень.
- Кожна частина має власний `requirements.txt`; кореневий об'єднує їх.

## Швидкий запуск

На Windows двічі клацніть [`start.bat`](start.bat). Це все: скрипт сам створить `.venv`, встановить потрібні бібліотеки та запустить сервер і вікно Messenger. Для першого запуску потрібен інтернет.

Потрібен Python 3.9+ з модулями `venv`, `pip` і Tkinter. Tkinter є системним компонентом Python: він не встановлюється через pip. Якщо його немає, встановіть збірку Python із підтримкою Tk або системний пакет `python3-tk` для вашої ОС.

Альтернатива для термінала з кореня проєкту:

```sh
python3 main.py
```

У Windows можна виконати `py main.py`. Перший запуск створює `.venv`, завантажує бібліотеки та запускає backend, а після його готовності — frontend. Наступні запуски перевіряють залежності через pip; уже встановлені відповідні версії повторно не завантажуються. Для завантаження відсутніх бібліотек потрібен інтернет. Помилка встановлення зупиняє запуск.

Після закриття вікна або Ctrl+C сервер, запущений цією командою, зупиняється.

Окремий запуск (також з автоматичним встановленням відповідних залежностей):

```sh
python3 main.py backend
python3 main.py frontend
```

Лише встановити бібліотеки:

```sh
python3 main.py --install-only
```

Для налаштувань скопіюйте `.env.example` у `.env`. За замовчуванням сервер працює на `ws://localhost:8765`, а дані зберігаються в `server_data.json` у корені. MongoDB необов'язкова; для неї вкажіть `MONGO_URI`. Для віддаленого frontend задайте `MESSENGER_SERVER_URL`. При зміні локального порту узгодьте `PORT` і `MESSENGER_SERVER_URL`.

### MongoDB Atlas

Залежності для Atlas встановлюються автоматично, включно з актуальним TLS CA bundle. Якщо Atlas повертає `SSL handshake failed`, не вимикайте перевірку TLS. Перевірте, що кластер активний, поточна публічна IP-адреса додана в **Network Access**, а рядок з'єднання скопійовано з **Atlas → Connect → Drivers**. Пароль у URI має бути percent-encoded, якщо містить спеціальні символи. Також мережа має дозволяти вихідні TCP-з'єднання на порт `27017`. Докладніше: [MongoDB Atlas troubleshooting](https://www.mongodb.com/docs/atlas/troubleshoot-connection/).

Щоб запустити застосунок без Atlas, залиште `MONGO_URI=` порожнім у `.env`; дані буде збережено локально у `server_data.json`.

Після встановлення залежностей доступні прямі запуски з кореня: `python -m backend.server` і `python -m frontend.main` (Python із `.venv`).
